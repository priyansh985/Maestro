# E0 implementation status — 30 October 2026

E0 is in progress on `codex/enterprise-e0`, based on
`fb1425235417879e1af227e691a3676ccedd68c0`. No release, push or deployment has
been performed. The enterprise design and E1–E4 backlog remain unchanged.

## Behavior implemented

- Production release evaluation always denies admission until a real trusted
  evidence verifier exists. Explicit simulations cannot grant admission.
- The offline validator runs six actual checks once, keeps separate logs and
  content hashes, continues after command failure and rejects changing inputs.
  Eight real integration lanes remain explicitly unassessed.
- Helpers use the actual policy bundle, principal and audit-event interfaces.
  External HMAC verification requires configured trust keys; serialized policy
  signatures do not include signing secrets. External signed-policy registry and
  audit replication operations explicitly report unavailability.
- Compliance exports report test evidence as unassessed rather than fabricating
  success. The default research app remains available; production boot is blocked.
- Canonical configuration and dashboard HTML are included in wheel builds, with
  resource fallbacks when the checkout is absent. CLI version and entry points
  match the package manifest.
- CI separates offline evidence, Windows runner contracts, deterministic
  reproduction, installed wheel checks and a non-root image smoke check. Actions
  are pinned to commit SHAs resolved from their upstream tags on October 30.

## Verification boundaries

Python 3.12/3.13 are the configured target matrix; clean installs and full tests
must establish support. Managed runtime downloads failed due network/extraction
errors. An official Python NuGet 3.13.11 archive was downloaded as a local
fallback; extraction finished and a clean environment was created. Dependency
installation and lock resolution are still in progress, so runtime support is
not yet established.
Existing source checks have used the preexisting Python 3.11.15 environment and
do not satisfy the new runtime matrix.

Docker is not installed on this host. Image CI is defined but has not run here.
The image requires a caller-supplied immutable Python 3.13 base digest; CI records
the resolved base and built image IDs. No image digest or successful image build
is claimed in this report.

Real database/RLS, OIDC provider, OS sandbox, recovery, hybrid network, cloud
models, external vertical adapters and browser acceptance remain unverified.
Production admission and startup remain disabled. E0 alone cannot establish an
enterprise-ready deployment.
